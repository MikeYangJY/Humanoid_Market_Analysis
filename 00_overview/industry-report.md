**从规模出货到可复制生产力：行业处于什么阶段，下一步验证什么**

研究日期：2026年9月27日。研究范围：以中国产业链为主，结合全球技术与客户案例。资料截止：本次能够核实的、截至研究日期已公开的信息；最新企业经营资料包括2026年半年报，部分产品和应用资料更新至2026年9月。

本报告综合行业生命周期、商业可行性、市场规模、护城河、外部因素、景气跟踪和主要矛盾框架。**不包含估值、企业盈利预测、利润分配分析或买卖与仓位建议。**商业可行性仅讨论客户需求、收费方式、技术前提和交付复制；市场规模中的价格是整机销售额的测算参数。

<a id="summary"></a>

## 核心判断

**人形机器人已跨过“只能做技术演示”的阶段，但整个行业尚未完成从卖设备到交付稳定生产力的转变。硬件出货进入快速扩张期，工业生产用途处于导入期后段，家庭通用服务仍处于更早的验证阶段。**这是基于公开证据作出的研究判断，并非行业统一分期。

当前最重要的两项变量是：一台机器人能否在明确任务中持续、低干预地完成工作；同一套方案能否以更少的部署工作复制到第二家、第三家客户。前者决定产品是否有用，后者决定行业能否规模化。

本报告的五个结论：

1. **长期需求明确，具体产品的需求仍需逐场景证明。**搬运、上下料、分拣和照护需求长期存在，但客户购买的是任务结果，未必需要双足、五指和完整人形。
2. **近期优先观察结构化或半结构化的企业场景。**制造和物流中的有限任务，比家庭中的开放任务更容易定义边界、验收和复制；并非所有工业工位都适合人形机器人。
3. **当前出货量只能部分反映生产力市场。**科研、数据采集、表演等均是真实需求，但其增长不能直接证明工厂或家庭用途已经成熟。
4. **中国已出现规模交付与制造迭代优势，长期格局仍未定。**双足和轮式产品、科研平台和工业设备的竞争基础不同，不宜把综合出货排名直接当作通用智能能力排名。
5. **最值得跟踪的是客户扩点复购、有效作业时长、人工接管和部署周期。**融资、展会、量产规划适合作为线索，不能单独确认商业化拐点。

## 一、研究边界与证据标准

### 1. 产品口径

本文区分三类对象：

| 类别 | 定义与例子 | 本报告中的用途 |
|---|---|---|
| 严格双足人形 | 双臂、躯干与双足的机器人，例如部分Unitree、Figure、Walker及Atlas产品 | 讨论人形本体、运动能力和双足路线 |
| 广义人形或类人移动操作机器人 | 具有类人上身或双臂，但采用轮式底盘等形态，例如Galbot、AEON及部分智元产品 | 讨论相同作业市场、替代方案及部分机构统计 |
| 其他自动化设备 | 工业机械臂、协作机器人、AMR、专机、四足机器人 | 作为竞争和互补方案，不直接计入本报告自建市场规模情景 |

**具身智能是一类技术范式，人形是一种产品形态，两者不能画等号。**具身智能进步可能同时增强人形机器人、机械臂和轮式机器人，因此其产业价值不会自动全部归于双足整机。

### 2. 证据如何分级

- **客户侧或法定披露：**客户公开确认的作业与合作、上市公司经营披露，优先用于确认发生了什么。经营披露中的技术描述仍可能属于企业自述。
- **厂商披露：**出货、性能、运行时长和订单等，保留其口径，不等同于独立测试。
- **第三方统计：**行业规模与份额，明确机构、时期和产品范围；不拼接不同口径。
- **本报告判断：**阶段、场景优先级、护城河和风险为分析推论。
- **情景假设：**未来站点、采购量、价格与跟踪阈值均显式标注，不作为已发生事实。

判断商业化进展时，依次区分：**演示—意向合作—试点—付费交付—稳定使用—同客户扩点—跨客户复制**。这些阶段不能互相替代。

## 二、行业发展阶段：硬件扩张与应用成熟度明显分层

### 1. 能核查的事实锚点

| 事实及时间 | 证据性质 | 能证明什么；仍不能证明什么 |
|---|---|---|
| Counterpoint：2026年上半年全球出货超过2.2万台，同比接近增长300%；娱乐表演与数据生产、科研合计仍超过60%，制造与仓储物流分别约13%、5% | 机构统计，包含多种形态 | 出货快速增长、生产用途开始扩大；不是全部机器已自主稳定工作 |
| 宇树：2025年纯人形机器人实际售出并交付终端客户超过5,500台，产量超过6,500台，明确排除双臂轮式等产品 | 公司声明，2026年1月 | 已形成规模生产和终端交付；不代表这些设备都用于工业生产 |
| 智元：第10,000台通用具身机器人于2026年3月28日下线 | 公司声明 | 累计制造规模提升；不是2026年单年销量，也不是全部为双足 |
| 优必选：2026年上半年全尺寸具身智能人形机器人产品与服务口径销量921台 | 2026年中期报告，9月24日披露 | 有规模销售；该业务涵盖多产品方向，不能全部视为工业双足Walker的部署量 |
| BMW：Figure 02在2025年试点累计约1,250个运行小时、搬运超过9万个部件，参与支持逾3万辆X3生产 | 客户披露 | 已进入实际生产流程；不是机器人独立完成整车制造，也未公开完整接管与维护数据 |
| Agility：2026年9月披露Digit 4累计超过6.5万运行小时，GXO累计搬运10万箱；新一代Digit 5预计2027年进入早期及后续普遍供货 | 厂商披露、历史商业合作获客户确认 | 运行经验有积累；旧代运行记录和新代性能、交付计划应分别看待 |

上述数据最有用的地方是展示不同层次的进展，而不是相加。特别是累计下线、年度出货、业务销量和累计运行小时属于不同统计维度。

### 2. 分场景判断

| 细分方向 | 本报告阶段判断 | 判断依据 | 跨入下一阶段需要看到的证据 |
|---|---|---|---|
| 科研、开发者、数据采集平台 | 早期成长期特征较明显 | 设备采购本身具有价值，开发生态能带动需求 | 用户持续活跃、代际升级采购、外部应用增加 |
| 表演、展陈、导览、租赁 | 从导入走向早期成长，区域差异大 | 特定活动和交互场景已形成设备需求 | 重复付费使用、运营利用率提升、热度消退后仍有需求 |
| 工厂、仓库有限任务 | 导入期后段，部分任务开始商业复制 | 已有客户现场运行及扩展项目 | 连续作业、低接管、同客户多站点与跨客户复购 |
| 开放环境多任务通用劳动力 | 导入期 | 缺少统一、可比较的长周期作业证据 | 陌生场景适应、异常恢复、服务能力同步成熟 |
| 家庭家务、老人日常照护 | 早期导入 | 环境开放、任务长、安全与隐私要求高 | 普通家庭持续使用、安全记录、隐性人工服务量透明 |

这里不机械采用“渗透率达到某个百分比即可进入成长期”的规则。人形机器人尚缺一致的分母：按工人、岗位、工位、企业还是任务工时计算，会得到完全不同的数值。

**后续更有用的渗透率是：在明确定义的一组可适配任务中，机器人完成的合格工作量占比。**公开数据目前不足以给出可信的全行业数值。

<a id="business"></a>

## 三、商业可行性：先确定谁付钱、为何付钱、如何验收

### 1. 需求存在，但形态选择必须接受替代方案检验

人形机器人的潜在价值，是利用为人设计的工具、通道和工作台，在任务变化时减少设备或场地改造。这个价值只有在现场得到验证才成立。

一个值得部署的场景，通常同时具备：任务重复且结果可验收；存在跨工位、物料变化或空间约束；现有专机的灵活性不足；机器人能够在安全边界内执行；失败能够快速恢复。

| 场景 | 客户痛点 | 为什么可能使用人形或类人机器人 | 主要约束及竞争方案 | 研究优先级 |
|---|---|---|---|---|
| 料箱转运、线边配送 | 重复搬运、班次衔接、物料流转 | 双臂操作与移动结合，接入已有料箱和台面 | 固定输送系统、AMR加机械臂；地面平整时双足优势有限 | 高 |
| 上下料、分拣、排序 | 品种变化、产线切换、姿态不固定 | 同一设备切换若干相近任务 | 节拍、定位、碰撞、卡料恢复；专机与协作机械臂 | 高，但需逐工位筛选 |
| 精细装配、柔性物操作 | 线缆、薄膜、小零件难以自动化 | 双手与触觉具有潜在适配价值 | 灵巧操作、质量一致性、失败后恢复难度高 | 中，技术验证为主 |
| 商业服务、导览、展陈 | 接待、互动、传播效果 | 类人交互与移动能力有吸引力 | 需求季节性、远程人工、屏幕终端等替代品 | 中，独立观察 |
| 科研与训练数据采集 | 缺少可编程本体和交互数据 | 购买硬件即可支持研发 | 需求受研究投入影响；采购不等于终端应用成功 | 高，作为独立市场 |
| 家庭家务、身体照护 | 家务时间、日常协助 | 适配人类生活环境的长期潜力大 | 杂乱环境、儿童宠物、隐私、身体接触安全 | 长期观察 |

上述优先级为本报告推论，不代表已有统一行业验证。照护尤其应拆分为递送物品、提醒、移动辅助与直接身体操作，不能从较简单任务的成功推导全部照护能力。

### 2. 商业模式画布

**客户与支付者：**工厂、仓储运营商、连锁服务企业、高校与实验室、活动运营商及个人。采购部门可能是生产部门，也可能是研发或宣传部门，付款预算决定了订单的含义。

**价值主张：**完成任务、减少重复操作、提升作业灵活性；科研平台提供可开发性，表演设备提供内容与互动价值。应分别验证，不能用一类需求替另一类背书。

**交付渠道与伙伴：**整机厂直接销售、系统集成商、渠道商和租赁运营商；现场通常需要生产或仓储系统提供者、设备集成伙伴和维护团队配合。

**收费方式：**整机销售、项目交付、租赁或RaaS、软件与维护服务。GXO与Agility在2024年6月确认多年RaaS合作，是历史商业模式证据；它本身不代表2026年行业普遍采用同样条款。[GXO官方公告](https://gxo.com/news_article/gxo-signs-industry-first-multi-year-agreement-with-agility-robotics/)

**核心资源与关键工作：**本体及控制系统、任务数据、模型训练评测、现场集成、异常处理、安全与服务网络。硬件出厂只完成了交付的一部分。

**客户承担的成本项目：**设备或租赁费用，以及集成、培训、工位改造、通信、维护、备件和人工协助。这里列出采购决策变量，不测算利润或投资回收期。

### 3. 商业化验证的实际门槛

对一项工业部署，至少需要回答以下问题：

1. 机器人执行的任务范围是什么，什么情况不在能力边界内？
2. 节拍、质量和安全要求是否由客户预先规定，并在现场验收？
3. 每完成一百次任务或每运行一小时，需要多少次人工干预？
4. 失败后能够自恢复，还是要技术人员到场？
5. 一名操作或维护人员实际能支持多少台设备？
6. 第二个站点需要重新采多少数据、重新调试多久？
7. 客户追加采购来自生产预算、研发预算，还是一次性展示预算？

**本报告判断：销售可行性已在部分细分市场成立；工业任务可行性已出现明确案例；跨任务、跨客户的普遍复制仍待证明。盈利可行性不在本次评估范围。**

## 四、技术路线与前置条件：从单点能力转向系统可靠性

### 1. 三层能力必须同时成立

| 层次 | 解决的问题 | 关键观察点 |
|---|---|---|
| 本体、关节与末端执行器 | 能不能稳定移动、承载、接触和操作 | 温升、寿命、背隙、力控、抓取可靠性、能耗、维护便利性 |
| 感知、模型与控制 | 看懂任务、生成动作并执行 | 遮挡与光照变化、语言歧义、陌生物体、实时性、异常恢复 |
| 系统与运营 | 能不能进入客户工作流程 | 与MES/WMS等系统衔接、调度、安全策略、数据管理、现场支持 |

本报告认为，步态和运动展示已不足以区分工业竞争力。更关键的是：**在物料变化、长时间运行和连续任务中，性能下降多少，以及系统能否自行处理错误。**

### 2. 大模型正在降低部分开发门槛，但未消除现场验证

2026年7月，NVIDIA公开了GR00T开发流程，将数据采集、策略训练、仿真评估与部署连接起来；Google DeepMind同月发布Gemini Robotics 2，强调全身控制与跨本体适应。这些为技术供给进步提供了证据，但其开发者结果不能直接当作所有工业环境中的作业保证。[NVIDIA技术说明](https://developer.nvidia.com/blog/develop-humanoid-robot-policies-end-to-end-with-nvidia-isaac-gr00t/)、[Google DeepMind发布说明](https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots/)

技术演进对行业存在两种并行影响：一方面，共用模型和工具让更多整机厂更快起步；另一方面，公开能力趋同时，现场数据、任务工程和服务交付的重要性会提高。**模型调用能力本身未必能构成长期壁垒。**

### 3. 长任务为何比单次演示困难

一个纯数学示例：假设一项任务有100个步骤，各步骤独立、成功概率均为99%，且没有重试，则一次完整成功的概率只有约36.6%；单步提高到99.9%时，完整成功概率约90.5%。真实任务存在相关性和重试机制，这不是机器人行业实测值。

该示例说明，商业部署需要同时提升单步准确性、错误检测和恢复能力。只公布精选视频或单个动作成功率，无法评价长流程的稳定性。

优必选2026年中期报告也把部分上下料VLA结果明确限定为实验室验证。研究时应保留测试环境限定，不能把某个实验项目的指标扩大为整机全部任务能力。[优必选中期报告，第14页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0924/2026092401451.pdf)

### 4. 双足、轮式和灵巧手不会只有一种答案

对于楼梯、不连续地面或高度依赖人体尺度的操作空间，双足具有潜在适配价值。对于平整地面的搬运、分拣和补货，轮式移动操作方案可能更容易满足稳定性和维护要求。具体优劣必须按场景测试。

同样，五指手适合追求工具通用性，但夹爪和专用末端执行器可能更适合明确任务。提高自由度会扩大动作空间，也会增加控制、数据和维护负担。

BMW的AEON试点采用轮式移动形态；这说明客户正在探索多种移动操作方案。该事实支持“按任务选择形态”的研究方法，不能单凭一个项目认定某种路线已经获胜。[BMW AEON案例](https://www.bmwgroup.com/en/news/general/2026/humanoid-robot-in-leipzig.html)

<a id="market-size"></a>

## 五、市场空间：把潜在需求、可服务任务与年度销售额分开

### 1. 修正并明确TAM、SAM、SOM的使用

| 概念 | 本报告采用的定义 | 人形机器人研究的落点 |
|---|---|---|
| TAM：总潜在市场 | 在明确功能、地域和时间范围内，理论上可覆盖的全部需求 | 可由移动操作机器人承担的任务工时及相关设备需求 |
| SAM：可服务市场 | 经技术、安全、预算、替代方案及交付能力筛选后可服务的部分 | 当前或目标年份能够满足要求的任务和客户集合 |
| SOM：可获取市场 | 某家企业在竞争和资源约束下实际能够取得的部分 | 按客户名单、验收能力、部署团队与供货能力评估 |

**SAM不等于已实现销售额，SAM/TAM也不等于现实渗透率。**将这些概念混同的简化不适合直接用于本行业。本文没有指定单家公司，因此不测算公司SOM。

### 2. 长期TAM应从任务工时出发

对于制造、物流等劳动替代用途，较合理的路径为：

> 可适配的任务工时 ÷ 单台机器人每年可交付的合格任务工时 = 潜在在用机器人数量。

再将其中的新增安装与替换需求，转换成各年份的销售量。科研和表演等非劳动替代用途需要单独估计，不能全部塞进工人工资替代模型。

这个方法要求先剔除或调整：更适合固定自动化的任务、无法达到安全和质量门槛的任务、客户没有支付意愿的任务，以及同一台机器人跨班次承担的重复工时。

目前缺少统一的任务工时分母和长期有效作业数据，**本报告不提供貌似精确的终局TAM点值，也不把全球劳动报酬总额直接称为机器人市场。**大规模劳动需求支持长期空间判断，不能直接确定年度销售额。

### 3. 2030年全球年度整机市场：三种可复算情景

以下是本报告自建的**条件情景，置信度低，不是机构预测或已确认订单**。目的是看清：数百亿元的年度市场需要多少真实采购站点与设备，而不是给出“必然达到”的数字。

口径为广义双臂人形及类人移动操作整机，包括轮式方案；不含普通工业机械臂、四足机器人和仅移动不操作的AMR。按全球市场计算，不把结果当作中国市场。

年度销量公式：

> 当年采购的工业、物流站点数 × 每站点当年采购台数 + 其他用途当年采购量。

当年采购量包括新增、扩容与替换，**不再另加替换量**。其他用途包含科研、数据采集、展陈及其他服务，不重复计算工业物流站点。该情景不以家庭全面普及为必要前提。

| 假设或测算结果 | 保守：缓慢渗透 | 中性：有限任务复制 | 积极：跨站点加速普及 |
|---|---:|---:|---:|
| 2030年发生采购的工业、物流站点 | 5,000个 | 15,000个 | 30,000个 |
| 每站点当年采购量 | 10台 | 15台 | 20台 |
| 工业、物流年度采购量 | 5万台 | 22.5万台 | 60万台 |
| 其他用途年度采购量 | 5万台 | 7.5万台 | 20万台 |
| **全年整机销量** | **10万台** | **30万台** | **80万台** |
| 加权整机销售单价假设 | 20万元 | 15万元 | 10万元 |
| **年度整机销售额** | **200亿元** | **450亿元** | **800亿元** |

表内全部站点、采购量及价格参数均为本报告假设。中性仅是中间路径，不表示已证明其发生概率最高。积极情景同时假设需求扩大与规模降价，两者不是可以分别保证的独立事实。

校验量级时，可参考Counterpoint对2026年全年超过5万台的预测，但不能把预测当成全年实际。仅以5万台作为计算锚，达到上述2030年销量分别需要约18.9%、56.5%、100.0%的四年复合增长。这个校验显示：积极情景要求非常快的持续扩张。[Counterpoint预测所在原文](https://counterpointresearch.com/en/insights/global-humanoid-robot-shipments-soar-nearly-300-percent-yoy-in-h1-2026?trk=article-ssr-frontend-pulse_little-text-block)

### 4. 如何解读这些数值

- 中性情景下，工业物流站点数减半、其他假设不变，全年销量从30万降至18.75万台，销售额从450亿元降至281.25亿元。**部署覆盖面是重要变量。**
- 中性情景下，单价降低20%而销量不变，销售额降至360亿元。出货增长和市场金额增长可能明显不同。
- 若年度整机销售额要达到1,000亿元，在10万元和20万元单价下，分别需要100万台和50万台年度销售。规模叙事必须能解释对应采购量如何出现。
- 整机销售额与其中零部件销售额存在上下游重复，不能直接相加形成行业规模。
- RaaS的运营收入与当期整机销售额不是同一口径，不能把存量设备的服务收入按新机售价重复计算。

需求情景还必须接受供给端约束：可靠量产、关键部件寿命、合格率、现场集成团队和服务覆盖中最慢的一项，可能决定实际交付速度。**公布的厂房产能不能替代合格交付能力。**

## 六、产业链与竞争格局：关注产品能力和交付能力分别积累在哪里

### 1. 产业链研究地图

| 环节 | 主要产品或能力 | 要验证的竞争优势 | 不能直接推导的结论 |
|---|---|---|---|
| 驱动与传动 | 电机、减速器、丝杠、轴承、驱动器、一体化关节 | 精度、寿命、温升、批次一致性、合格供货 | 某种丝杠或减速器必然成为所有机器人的标准方案 |
| 感知 | 视觉、深度相机、力矩与触觉、位置反馈 | 真实场景稳定性、标定能力、数据质量 | 传感器越多，整机任务能力必然越强 |

| 算力与基础软件 | 边缘计算、训练平台、仿真、开发框架 | 工具链成熟度、适配效率与开发生态 | 模型开源后应用壁垒全部消失 |

### 3. 中国与海外如何比较

从已披露的交付规模与产品迭代看，中国厂商在制造、硬件可获得性和多层次需求覆盖上具备明显进展。海外案例提供了工业客户运行与软件体系的不同验证路径。

但“硬件在中国、软件在海外”是过度简化。国内厂商也在推进模型与任务数据，海外厂商也在建立制造与执行器能力。应按四个问题逐家公司比较：**产品能做什么、能稳定做多久、能复制到哪里、客户为何继续采购。**

本报告不采用一个跨产品、跨用途的份额数字来宣布终局龙头。科研设备量大、工业服务能力强、通用模型表现领先，是不同维度的优势。

<a id="moats"></a>

## 七、护城河：目前主要是候选优势，需要长期验证

### 1. 供给优势：工艺与软硬件协同

零部件的潜在壁垒来自材料与工艺、寿命及一致性测试、精密制造和稳定批量交付。整机的潜在壁垒来自传动设计、控制、感知、末端与任务策略共同优化。

单项参数领先不一定带来系统领先。可核查的评价应包括相同任务和工况下的故障、维护、性能衰减与部署工作量，而不是只看最大负载、最高速度或自由度。

**失效机制：**技术路线更换、客户自制、竞争者提高合格率，或开放模型和工具缩小原有差距。某一零部件技术有壁垒，也不意味着其在未来整机中的用量永远不变。

### 2. 需求优势：经验证的集成和转换成本

当设备深度连接工位、安全流程、生产软件和技能库，更换供应商可能需要重新测试、重新培训、重新验收。这种真实转换工作构成潜在客户黏性。

但不能把“接入复杂、调试困难”本身当作优质护城河。它也可能妨碍首次采购和扩点。更理想的组合是：首次部署容易，持续表现可靠，后续扩展能复用已有资产。

**验证方法：**同客户追加站点、迁移任务所需工时、软件及技能资产复用比例、故障支持满意度。没有这些证据，仅凭进入客户名单不能认定强黏性。

### 3. 规模优势：制造学习与有效数据积累

制造规模可以改善采购、工艺学习和服务覆盖；更多真实作业可以产生边界案例，使模型和控制进一步改善。但这一反馈循环需要四个条件：数据有权使用、格式可用、对新任务有帮助、更新能安全部署。

**数据多不等于数据壁垒强。**重复的简单轨迹未必有新增价值，客户数据可能不能跨客户使用，不同本体的数据也未必能直接迁移。

同样，数据学习效应不等于已形成网络效应。只有增加一个用户能够可验证地提高其他用户的产品价值，才适合讨论网络效应。现阶段不足以据此断言整机市场会赢家通吃。

**本报告判断：更值得验证的壁垒组合是“可靠硬件＋任务数据＋快速部署＋持续服务”。由于本次不做盈利分析，也缺少长期稳定运营数据，不对任何企业作已确认的宽护城河评级。**

<a id="external-factors"></a>

## 八、外部因素：支持产业发展，也会改变可服务市场

| 维度 | 可观察因素 | 对行业的传导 | 研究处理 |
|---|---|---|---|
| 政策与标准 | 产业支持、标准制定、公共采购 | 降低研发与验证门槛；改变验收要求 | 区分方向性文件、资助、采购，以及真正生效的要求 |
| 经济与用工 | 工厂、物流的投资意愿和岗位招工情况 | 影响采购预算、任务选择与替代动力 | 缺工需落实到岗位，宏观用工规模不能直接转换成机器人订单 |
| 人口与社会接受 | 老龄化、危险或重复岗位需求、工人接受度 | 长期增强协助需求；影响部署方式 | 对家庭及身体照护保持更高证据要求 |
| 技术与国际供应链 | 基础模型、计算平台、精密设备、数据跨境与本地服务 | 同时影响能力、可获得性及全球部署 | 逐产品核实适用限制，不预设所有公司遭遇相同约束 |

国家统计局披露，2025年末中国60岁及以上人口为3.2338亿，占总人口23.0%。这支持对长期协助需求的重视，但不证明这些人口能够或愿意购买人形机器人。[国家统计局人口解读](https://www.stats.gov.cn/sj/zxfbhjd/202601/t20260119_1962338.html)

标准方面，《人形机器人与具身智能标准体系（2026版）》已发布；全国标准信息平台中的《人形机器人安全要求 第4部分：公共服务领域》仍显示为正在起草的推荐性国家标准计划。**标准体系、标准计划和已生效的具体标准是不同状态**，不能将其混称为已经全面实施的强制准入规则。[标准体系发布信息](https://www.fujian.gov.cn/zwgk/ztzl/zswzjjylzzccs/gj/202603/t20260302_7103291.htm)、[国家标准计划状态](https://std.samr.gov.cn/gb/search/gbDetailed?id=529F2216CC2CD483E06397BE0A0A4F73)

外部因素对基本面的主要修正路径为：通用模型改善可能扩大可服务任务，同时削弱部分软件先发优势；安全要求明确可能提高初期验证工作，但帮助建立采购信任；如果公共及研发采购放缓，依赖这类预算的出货可能波动，即使工业技术仍在进步。

<a id="tracking"></a>

## 九、景气跟踪：从“生产了多少”改进到“客户持续使用了多少”

**当前综合判断：硬件出货景气向上；工业应用的广度与可复制性正改善，但缺少全行业统一的连续作业和复购序列，尚不能认定全面商业化已经完成。**

跟踪锚点应放在下游任务需求与客户使用。传导顺序为：客户预算与验收任务—试点转付费—部署扩点—整机交付—零部件补货。不同项目时滞差异很大，现阶段不预设一个全行业固定领先月数。

| 指标 | 属性与频率 | 本次基线或数据状态 | 需要记录的口径 |
|---|---|---|---|
| 试点转付费项目比例 | 前瞻；月度或季度 | 缺少跨厂商统一公开数据 | 同一批试点、相同观察期；剔除意向合作 |
| 同客户扩点复购 | 前瞻兼验证；季度 | 有项目拓展案例，缺少统一复购率 | 客户、站点、任务、付款用途和追加台数 |
| 新站点部署周期 | 前瞻；每项目、季度汇总 | 多数未公开 | 从进场到客户验收；不能从合同签署开始混算 |
| 付费部署设备数与活跃设备数 | 同步；月度 | 有出货数据，活跃比例缺失 | 终端交付、验收、持续作业分列 |
| 有效作业时长与任务吞吐量 | 同步；周度或月度 | 有BMW、Agility样本，不能行业外推 | 单台/全队、累计/当期、在任务中/总在线时间 |
| 人工接管与故障恢复 | 同步；周度或月度 | 缺少标准化公开序列 | 每百次任务或每小时次数、处理时长、重试定义 |
| 用途与形态结构 | 同步；半年度，月度收集线索 | 采用前文Counterpoint同期分类 | 双足/轮式、科研/生产/服务、关联/外部客户 |
| 合格交付与零部件重复采购 | 上下游联动；月度或季度 | 通常需要公司披露和客户核实 | 样件、备货、量产订单分开，去除重复计算 |
| 新产品交付兑现 | 事件及季度 | 发布计划与供货计划可查 | 计划日期、首批交付、规模交付分别记录 |
| 安全事件与服务能力 | 持续收集、月度汇总 | 缺乏统一分母 | 事故严重度、作业暴露量、停机与整改；不能仅统计新闻数量 |

“缺少公开数据”是一个信息状态，不等于指标为零，也不等于企业没有相关能力。无法获得现场记录时，应降低判断置信度，而不是用估算补齐表格。

### 建议的研究触发条件

下列条件是本报告提出的审查规则，**不是行业标准，也不是已发生事实**：

- **上调某一任务商业化成熟度：**至少三家无关联付费客户、合计三个及以上站点，连续三个自然月按客户既定节拍与质量要求运行，并出现至少一次同客户追加采购；同步核实人工支持量。
- **上调方案复制能力判断：**在任务复杂度相近的样本中，新站点部署周期连续两个季度缩短，且质量和接管情况没有恶化。
- **下调短期放量判断：**规模交付连续两次错过正式披露节点，或出货增长但终端活跃使用和客户扩点连续两个季度没有相应证据。
- **重新评估技术或应用边界：**发生与产品设计相关的严重安全问题，或运行方式依赖此前未披露的大量人工操作。

建议公开新闻按周收集，经营和客户证据按月整理，季度重新评估。没有成熟的日频行业统计时，不为追求“高频”而使用无关热度替代基本面。

<a id="bottlenecks"></a>

## 十、主要矛盾与可证伪结论

### 1. 两个主要矛盾

**第一，硬件可获得性提升，是否足以转化为客户所需的稳定作业能力。**当前最容易混淆的是动作演示、能执行某任务与长期交付该任务三者的差别。

**第二，单个样板项目的成功，是否能够在人工支持没有同步增加的情况下扩展到更多现场。**如果每增加一台设备都需要相似幅度的现场工程或接管支持，规模制造也未必能带来应用的规模扩散。

没有分析股价和估值，因此本报告不声称“市场已经定价了什么”或“市场低估了什么”。可以确认的是，行业公开叙事高度重视技术突破和出货，研究上还需要补齐任务结果与复制证据。

### 2. 本次适用的产业验证链

> 技术能力 → 客户任务成立 → 付费验收 → 持续使用 → 扩点复购。

| 环节 | 当前判断 | 主要断点 |
|---|---|---|
| 技术能力 | 运动与部分操作能力不断进步 | 无法覆盖长尾场景与异常处理 |
| 客户任务成立 | 工业物流已有明确样本 | 人形方案未必优于其他自动化方式 |
| 付费验收 | 已存在真实商业销售与合作 | 一次性采购、关联采购、研发预算与生产采购混淆 |
| 持续使用 | 有运行记录，行业数据仍有限 | 接管、停机、维护和服务负担不透明 |
| 扩点复购 | 正在验证，是最重要后续节点 | 方案过度定制，难以跨站点迁移 |

若持续使用和复购得到验证，优先受益的是能够解决实际瓶颈、并进入合格交付体系的部件、整机与服务能力；并不自动惠及所有带有“人形机器人”标签的企业。

若验证停滞，首先需要下修工业用途的采购站点扩张速度，再重算年度市场情景。科研、表演等独立市场仍可能增长，不能因此把整个行业归零；同样，它们的增长也不能消除工业应用的验证缺口。

### 3. 需要主动反驳的六种判断

| 容易出现的判断 | 更严格的检查 |
|---|---|
| 机器人有手有脚，因此可以替代全部人类工作 | 拆解任务、环境、质量、安全和人工支持边界 |
| 出货高速增长，因此通用工业应用已经成熟 | 核查产品形态、购买用途和持续使用情况 |
| 某大厂公布产能，因此未来销量已经确定 | 分开记录规划、合格产量、终端交付与复购 |
| 零部件价值量高，因此相关公司必然受益 | 核查技术路线、实际用量、客户认证与供货阶段 |
| 数据最多的公司一定最终胜出 | 验证数据权利、质量、可迁移性和迭代效果 |
| 人口老龄化，因此家庭机器人即将普及 | 核查功能边界、支付意愿、家庭安全与实际使用 |

**本报告的最终产业判断是：人形机器人具备持续扩展的需求基础和技术条件，未来数年的决定性进展将来自有限任务的可靠交付与多站点复制。下一阶段最有价值的新证据，是客户在看清运行表现后继续增加部署。**

## 附录：框架使用与资料限制

| 分析框架 | 本次采用的内容 | 本次处理边界 |
|---|---|---|
| industry-lifecycle-stage | 用户结构、应用成熟度、供需及阶段分层 | 不照搬未定义分母的渗透率阈值 |
| business-viability-analysis | 商业画布、真实需求、技术前提、交付可行性 | 不做利润可行性和UE盈亏测算 |
| market-size-analysis | TAM/SAM/SOM、需求与供给约束、三情景敏感性 | 明确区分存量与年度流量，纠正SAM等概念的简化 |
| moat-analysis | 供给、需求、规模优势及失效机制 | 仅评价潜在壁垒，不用盈利指标确认宽护城河 |
| external-factors-analysis | 政策、经济、社会、技术的传导 | 历史示例和数值须按研究时点重新核实 |
| prosperity-tracking | 前瞻、同步和产业链跟踪 | 缺失值保留为空缺，不虚构月度行业数据 |
| main-contradiction | 收敛关键变量、识别传导断点 | 将链条限定在产业验证，不延伸到盈利预期和股价 |
| investment-framework | 判断的验证要求、风险与证伪意识 | 不给投资收益来源、仓位、买卖时机或止损建议 |
| valuation-analysis、profitability-analysis | 未使用 | 本期研究范围不包含 |

上述框架用于组织研究问题；事实、推断和情景假设按证据性质分别标注。统一方法见[研究方法](../research-method.md)。

资料限制：没有开展企业访谈或现场测试；企业声明不等同于独立审计；不同任务的成功率、运行小时和出货定义可能不一致。未取得的关键数据包括全行业活跃部署率、同批试点转付费率、统一人工接管率、真实任务工时分母和跨客户部署周期。因此，当前规模数据的置信度高于远期数量情景，局部应用判断的置信度高于通用机器人普及时间判断。
