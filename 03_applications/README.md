# 03｜下游应用

[研究首页](../README.md) · [研究地图](../research-map.md) · [应用专题模板](../templates/application-topic.md)

**状态：研究提纲，尚未完成逐行业专题。** 已有场景比较见[行业报告的商业可行性](../00_overview/industry-report.md#business)。

**研究单位采用“行业 → 工作流 → 具体任务 → 现场部署”。** 比如汽车制造只是行业，上下料才是候选任务；还需确定零件、工位、节拍和质量，才能判断机器人方案。

## 拟覆盖范围

| 行业/用途 | 可拆分的任务 | 首要验证问题 |
|---|---|---|
| 制造 | 上下料、线边物料、分拣排序、检测辅助、装配 | 质量与节拍、停线代价、现有专机或机械臂是否更合适 |
| 仓储物流 | 拆码垛、料箱转运、拣选、订单包装 | 物体及包装变化、持续吞吐、异常恢复与系统接入 |
| 商业服务 | 洗衣、餐饮辅助、零售补货、酒店服务 | 多门店复制、流程变化、人员协同、现场服务 |
| 家庭与日常协助 | 整理、清洁辅助、递送、提醒 | 陌生家庭、长任务、照看负担、支付意愿；身体照护另行研究 |
| 科研、数据采集、表演与展陈 | 开发平台、数据生产、活动及交互 | 采购预算、重复使用和利用率，独立于生产劳动替代需求 |

这里不预判任务均已可商业部署；研究结论需逐项建立。

## 固定比较对象

在相同任务下比较人工、流程重设计、固定专机、工业/协作机械臂、轮式移动操作与双足人形。人形的价值应由场景证明，不作为分析起点的既定答案。

## 每个客户案例应保留的条件

记录客户及证据日期、采购用途、现场和机器人版本、任务边界、模型版本（未知就保留未知）、验收标准、工作时长、完整成功率、人工介入、维护、部署工作和后续扩点。

分开统计展示、意向合作、试点、付费验收、持续使用、同客户扩点和跨客户复制。不能把整机厂的产能规划或模型成功演示替代应用成熟度证据。

## 如何反馈给上游研究

如果任务失败，先区分需求设计、硬件、模型、控制、系统集成和运营原因。把可验证瓶颈反馈到[硬件](../01_hardware/README.md)或[模型](../02_models/README.md)模块；客户采纳及使用变化记入[持续跟踪](../04_tracking/README.md)。

市场测算先明确可适配任务工时及合格产出，再估在用设备、新增和替换需求。科研、展示等用途单独估计，避免统一按劳动替代测算。
