# 证据记录模板

[跟踪入口](../04_tracking/README.md) · [证据标准](../research-method.md)

**记录编号：**［日期-主题-序号］　**关联专题/问题：**［链接］

| 字段 | 待填写内容 |
|---|---|
| 发生时间 / 发布日期 / 核对日期 | 分别记录；未知不推定 |
| 来源与直接链接 | 原始论文、客户、公司披露或统计机构 |
| 证据性质 | 事实披露 / 实验 / 计划 / 推断 / 情景 |
| 对象与版本 | 公司、产品、机器人、模型、客户和地点 |
| 核心内容 | 只写来源实际支持的内容 |
| 数值与口径 | 单位、分母、期间、样本量、形态、范围 |
| 运行条件 | 任务、适配、人工、工况、时限和成功标准 |
| 能证明什么 | 与当前研究判断的具体关系 |
| 不能证明什么 | 缺失资料与外推边界 |
| 是否改变判断 | 维持 / 上调 / 下调 / 尚不足判断，并说明原因 |
| 后续核实 | 需要取得的下一条证据 |

涉及非公开访谈时，仅将已确认可以公开的内容纳入仓库。
