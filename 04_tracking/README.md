# 04｜持续跟踪

[研究首页](../README.md) · [研究地图](../research-map.md)

**跟踪的核心是：新的证据是否改变了可靠交付和规模复制的判断。**

| 页面 | 用途 | 当前状态 |
|---|---|---|
| [统一指标](metrics.md) | 定义分母、频率、来源和跨模块责任 | 已建立定义；多数运营指标尚缺公开连续数据 |
| [待验证问题](questions.md) | 从当前判断出发，明确需要补什么证据 | 已从两份报告提炼；不是已验证结论清单 |
| [证据记录模板](../templates/evidence-record.md) | 记录事件与证据条件，方便回溯 | 可用于后续新增资料 |

当前基线来自[行业报告](../00_overview/industry-report.md#tracking)和[模型报告](../02_models/model-report.md#tracking)，不把局部客户案例外推为全行业均值。

建议按周收集线索、按月核对可用指标、按季度复审主要判断。这是研究工作节奏，不表示仓库已经接入实时数据或自动监控。
