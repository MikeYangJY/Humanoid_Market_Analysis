# 统一跟踪指标

[跟踪入口](README.md) · [待验证问题](questions.md) · [研究方法](../research-method.md)

指标框架更新：2026-09-28；现有资料基准为2026-09-27。以下定义用于后续更新；除明确链接的样本外，不填充未经取得的数值。

| 指标 | 分母与条件 | 频率/责任模块 | 当前证据状态 |
|---|---|---|---|
| 终端交付 | 当期交付数量；形态、用途、地区分列，累计下线另列 | 季度；总览/应用 | [行业样本](../00_overview/industry-report.md#lifecycle)，口径不统一 |
| 付费活跃部署 | 当期已付费、实际作业的设备/站点；定义最低活跃标准 | 月/季；应用 | 缺少全行业统一序列 |
| 试点转付费 | 同批试点在固定观察期内达到付费验收的比例 | 季度；应用 | 待获取客户批次数据 |
| 扩点与留存 | 同客户增加站点、任务或设备；续约与停用分列 | 季度；应用 | 有案例，统一复购率未知 |
| 新站点上线投入 | 达同等验收标准的新增数据小时、示范数、工程人天、进场至验收天数 | 每项目；应用/模型 | 需匹配任务难度和硬件成熟度 |
| 完整任务成功率 | 达质量与时限的完整成功/全部启动回合；自主与人工辅助分列 | 周/月；应用/模型 | [模型实验](../02_models/model-report.md#evidence)不可直接跨基准比较 |
| 人工负担 | 每百机器人作业小时的接管次数、接管分钟、等待及其他支持工时 | 周/月；应用 | 零接管也应报告观察时长与样本量 |
| 合格吞吐 | 合格产出/计划作业小时；另报实际运行小时与停机 | 周/月；应用 | 不以动作 Hz 或纯执行时间替代 |
| 自主恢复 | 可识别错误中，无人工恢复并完成任务的比例，附恢复耗时 | 周/月；模型/应用 | 需要失败回合记录 |
| 硬件可靠性 | 固定工况下寿命、温升、故障、维护与批次差异 | 每测试/季度；硬件 | 专题待开展，不能用峰值参数替代 |
| 合格批量供货 | 样件、验证、量产供货、重复采购分列 | 月/季；硬件 | 需客户或明确经营披露 |
| 分机型整臂外购比例 | 外购完整臂/同机型装机臂需求；OEM、代际、形态分列，单卖关节另计 | 季度/换代；硬件 | [采购路径](../01_hardware/arms-and-oem-sourcing.md#sourcing)已有分析，统一份额未知 |
| 供臂订单兑现与复购 | 同批次订单对应单臂出货、验收、取消、退货；同代复购及跨代选型分列 | 月/季；硬件 | [公开供货案例](../01_hardware/arms-and-oem-sourcing.md#evidence)存在，连续批次数据不足 |
| 机械臂用途结构 | 装机、研发采集、备件及替换分别记录；核对SKU与库存，订单各阶段不重复累计 | 月/季；硬件/模型 | 研发设备不能按整机产量推算；目前缺统一拆分 |
| 数据迁移与版本退化 | 相同设置下新数据对保留任务的收益；旧任务回归表现 | 每版本；模型 | 厂商实验线索，持续部署数据不足 |
| 支持资源伸缩性 | 活跃部署增加时工程及支持人力变化；计入外包和伙伴工作 | 季度；应用/模型 | 关键待访谈项 |

## 统一证据链

技术可行 → 客户任务成立 → 付费验收 → 持续使用 → 同客户扩点 → 跨客户复制。

各阶段分别记录，后面的阶段不能由前面自动推出。科研、展示等用途有独立价值，不能替生产应用背书。

## 何时调整判断

将某任务的“稳定商业复制”作为较强判断时，建议核查至少三家无关联付费客户、三个及以上站点、一个季度按预设质量和节拍运行，并有扩点证据，同时披露或核实人工支持。该门槛是本仓库的研究建议，不是行业标准，也不是已实现事实。

若新站点上线投入下降但质量、接管或维护恶化，不上调复制能力判断。若更多数据只改善离线损失，不据此上调现场可靠性。不同风险任务需设置适合自身的要求。
