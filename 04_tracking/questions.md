# 当前待验证问题

[跟踪入口](README.md) · [统一指标](metrics.md)

更新于2026-09-29；既有行业及供货判断依据截至2026-09-27的资料，新增问题来自2026-09-29机械臂选型框架。下列问题来自现有报告和专题，状态描述证据是否齐全，不代表公司一定不存在相关能力。

| 问题 | 当前判断/状态 | 下一份最有价值的证据 | 归属 |
|---|---|---|---|
| 出货增长有多少转为持续生产作业？ | 用途明显分层；行业活跃使用未知 | 按形态、任务、采购预算分组的付费活跃设备与使用量 | 总览/应用 |
| 人形方案在哪些任务优于替代方案？ | 需逐任务证明 | 同现场、同验收标准下与人工、专机、机械臂及轮式方案比较 | 应用/硬件 |
| 新模型是否减少了实际人工负担？ | 实验和伙伴案例支持部分进步 | 同客户、同任务、跨版本的质量、吞吐、支持工时 | 模型/应用 |
| 新客户适配投入是否持续下降？ | 尚缺可比跨客户数据 | 相近任务从首站到后续站点的数据、人天和上线周期 | 模型/应用 |
| 当前瓶颈在模型、硬件还是运行系统？ | 不同任务可能不同 | 失败分类及单因素改动前后结果 | 三个专题共同 |
| 哪些上游性能真正限制交付？ | 供臂专题已提出验证方向，任务实测仍待补充 | 指定任务工况下的寿命、温升、接触可靠性及停机 | 硬件/应用 |
| 整机增量流向整臂外购、关节采购还是OEM自研？ | [三种路径](../01_hardware/arms-and-oem-sourcing.md#sourcing)并存，加权份额未知 | 同一OEM分机型、代际的实际采购配置；分开识别采购变化与客户结构变化 | 硬件 |
| 供臂订单能否转为持续交付和跨代复购？ | 有合作和首批交付，不能外推长期份额 | 订单批次的出货、验收、取消及下一代选型；核对交期和合格产能 | 硬件 |
| 研发采集采购是否被混入人形装机需求？ | 用途与SKU拆分不足 | 机械臂最终用途、工位配置、库存及重复计量核对 | 硬件/模型 |
| 装完整套末端后，机械臂能否满足目标任务？ | [六维能力与场景优先级](../01_hardware/arm-capability-and-selection.md#scenarios)已有框架，未做跨厂商实测 | 同安装与工具配置下的负载重心、全路径、接触质量、节拍及持续运行测试 | 硬件/应用 |
| 开放接口和学习生态是否减少实际适配投入？ | 具备接口不等于流程已跑通，效率收益待验证 | 对应版本接口与同步日志、采集到部署的完整复现，以及同等任务下的工程人天 | 硬件/模型 |
| 数据能否跨客户改善基座？ | 有研究机制，权利和部署收益待核查 | 使用权、训练对照、保留客户增益及旧技能退化 | 模型 |
| 少样本设置能否达到生产门槛？ | 公开短任务结果不能替代长期验证 | 全流程示范投入、后台工程工作、固定节拍和持续运行 | 模型/应用 |
| 客户购买的是独立模型还是整体方案？ | 交付路径并存，合同拆分不足 | 模型、集成、硬件与支持的合同边界和续约原因 | 模型/应用 |

下一轮可以配对推进一个硬件专题与一个应用任务，优先取得跨版本、跨站点和真实失败的数据。公开资料已回答的架构问题留在阅读材料；访谈时间主要用于数据缺口、交付流程和反证。
