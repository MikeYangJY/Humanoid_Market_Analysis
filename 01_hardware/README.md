# 01｜上游硬件

[研究首页](../README.md) · [研究地图](../research-map.md) · [硬件专题模板](../templates/hardware-topic.md)

**状态：研究提纲，尚未形成零部件专题报告。** 当前已有背景见[行业报告的产业链地图](../00_overview/industry-report.md#value-chain)。

**研究问题：什么物理约束限制了任务能力，哪种方案能在对应工况下可靠批量交付。**

## 拟覆盖范围

| 方向 | 候选研究对象 | 优先验证的问题 | 与其他模块的接口 |
|---|---|---|---|
| 驱动与传动 | 电机、减速器、丝杠、轴承、驱动器、一体化关节 | 同负载和循环工况下的精度、温升、寿命、效率及一致性 | 动作控制频率、力控与持续作业 |
| 手与末端 | 灵巧手、夹爪、腱绳/连杆、工具快换 | 抓取适应性、接触可靠性、耐久、维护；五指是否必要 | 任务质量、触觉学习、失败恢复 |
| 感知与反馈 | 相机、深度、编码器、力矩、六维力及触觉 | 信号质量、遮挡、标定、同步、环境稳定性 | 模型输入、控制闭环、异常检测 |
| 算力与通信 | 端侧处理器、推理计算、通信链路 | 实际模型负载下的延迟、功耗、温度及断网行为 | 模型部署与控制调度 |
| 电源与热管理 | 电池、供电、充换电、散热 | 有效作业续航、充电停机、峰值与连续工况 | 班次覆盖、利用率与维护 |
| 整机结构与集成 | 双足/轮式、材料结构、线束、连接器、防护 | 系统可靠性、可维护性、装配及一致性 | 客户空间、安全边界与服务 |

这些是待研究对象，不预设某种技术路线必然成为标准配置。零部件方案按任务工况比较，企业作为证据和竞争对象放进对应专题。

## 每篇专题的逻辑

从客户任务提出性能要求 → 比较技术方案 → 核对真实工况与寿命 → 判断供应商验证和量产阶段 → 研究用量、外购比例与市场边界 → 给出跟踪指标和反证。

必须分开记录“产品存在、送样、客户验证、定点、量产供货、重复采购”。某企业研发了部件，不能自动推断它进入特定客户供应链。

若估算部件市场，应注明本体形态、单机配置、外购率、价格与年度整机量，避免把所有机器人视为同一种物料清单，也不与整机市场重复加总。

## 首批专题的选择建议

先从[应用模块](../03_applications/README.md)选定一项任务，再选择直接限制该任务的部件。若从灵巧手开始，就同时比较夹爪及其他末端，并追问性能收益能否在合格吞吐、接管和维护上体现。
