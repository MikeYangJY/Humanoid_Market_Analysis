除已链接的机械臂供货逻辑与选型框架外，其余方向仍待专项研究，不预设某种技术路线必然成为标准配置。零部件方案按任务工况比较，企业作为证据和竞争对象放进对应专题。

## 每篇专题的逻辑

从客户任务提出性能要求 → 比较技术方案 → 核对真实工况与寿命 → 判断供应商验证和量产阶段 → 研究用量、外购比例与市场边界 → 给出跟踪指标和反证。

必须分开记录“产品存在、送样、客户验证、定点、量产供货、重复采购”。某企业研发了部件，不能自动推断它进入特定客户供应链。

若估算部件市场，应注明本体形态、单机配置、外购率、价格与年度整机量，避免把所有机器人视为同一种物料清单，也不与整机市场重复加总。

## 后续专题的选择建议

先从[应用模块](../03_applications/README.md)选定一项任务，再选择直接限制该任务的部件。若从灵巧手开始，就同时比较夹爪及其他末端，并追问性能收益能否在合格吞吐、接管和维护上体现。

后续专题形成正文后，在本页增加标题、资料日期、关键结论和链接；未完成研究的方向继续标为“待开展”。
