# 协作厂商向人形整机厂商供臂：需求与采购逻辑

[上游硬件](README.md) · [研究首页](../README.md) · [模型与控制](../02_models/README.md) · [持续跟踪](../04_tracking/README.md)

整理日期：**2026-09-28**；原研究与本篇公开资料核对截至 **2026-09-27**。本篇提炼供货逻辑，不展开原研究的数量预测、盈利测算及估值。

**核心判断：协作厂商的机会，来自部分人形整机厂商用外购机械臂换取开发时间、工程资源和交付确定性。人形产量增长能否转成供应商的持续订单，取决于具体机型的采购路径、供应商份额和交付表现。**

本专题属于“上游硬件 → 机械臂与上肢总成”：这里的直接客户是人形整机厂商（OEM），研究的是产业分工与采购。终端工厂、仓库如何使用机器人，进入[下游应用](../03_applications/README.md)。

<a id="scope"></a>

## 1. 先区分三类需求

| 需求池 | 购买目的 | 统计边界 |
|---|---|---|
| 整机装机用完整臂 | 直接装入人形整机，承担上肢动作 | 核心市场，按单条机械臂计量；双足与轮式平台分列 |
| 研发与数据采集用臂 | 遥操作、训练、测试及样机验证 | 相邻需求，按工位配置和利用率研究；不一定装入整机，也不一定采用专用人形臂 |
| 单独销售的臂部关节 | OEM购买关节后自行设计和组装机械臂 | 按关节计量；排除已含在完整臂销售中的内部关节 |

手、腿部和腰部关节另设专题。采购方是人形厂商，不代表采购的所有机械臂都进入当年整机产量；研发用臂也可能已被计入传统协作机器人出货。数量和收入均须按最终用途去重。

<a id="sourcing"></a>

## 2. 客户在购买什么，为什么外购

初创厂商希望尽快完成样机，跨行业进入者需要按期推出产品，已有整机厂商可能为特定机型补充性能或产能，模型团队则需要稳定的采集平台。共同点是：采购决定不仅比较物料成本，也比较设计、调试、测试、良率爬坡、维护和延期的代价。

| 采购路径 | OEM承担的工作 | 协作厂商可争取的位置 |
|---|---|---|
| 自研并组织制造整臂 | 主导构型、关节选型、控制与制造验证 | 能否进入其部件供应链需另行验证 |
| 采购关节、自行组臂 | 保留构型与集成控制，采购成熟关节 | 独立关节供货；与整臂业务分开统计 |
| 采购完整机械臂 | 重点完成整机、模型和任务集成 | 完整臂及约定范围内的控制、调试和服务 |

**分析单元应是“OEM—机型—代际—批次”。** 同一家企业可以同时采用多条路径。放量后，自研的固定投入可能更容易摊薄；外部供应商也可能借助跨客户规模提供更好的成本与质量。不能预设大客户最终必然自研，或外购率必然提高。

<a id="capabilities"></a>

## 3. 协作厂商能复用什么，还要补什么

可复用的基础包括伺服与运动控制、力反馈和标定经验、关节集成、加工装配、寿命测试、质量体系及维修服务；各厂商具备的能力深度需要逐一核实。

人形应用仍需重新验证轻量化、全工作空间负载、动态惯量、功耗与温升，以及肩肘腕布局、双臂协调和全身控制。成熟协作产品的可靠性经验，不能直接替代新型号在移动本体上的验证。

**控制接口是产品选型的一部分。** 希望自研全身策略的OEM，需要确认底层控制权限、反馈信号、时间同步和故障责任。封闭的整臂控制系统可能增加适配成本；硬件销售本身也不赋予供应商客户数据的使用权。相关分析见[模型与控制分层](../02_models/model-report.md#scope)和[数据及模型壁垒](../02_models/model-report.md#moats)。

力控、自由度和传感配置应由任务决定。接触丰富的任务可能更需要力反馈；其他任务则可能优先考虑轨迹、重量和成本。配置更高不自动意味着更容易中标。

<a id="demand"></a>

## 4. 整机增长如何传导到供臂订单

**人形及研发预算 → 具体机型或工位需求 → 选择外购 → 协作厂商中标 → 合格交付与验收 → 持续复购。**

装机需求可按机型拆解：

> 协作厂商装机用完整臂需求 = Σ（各OEM各机型产量 × 每台臂数 × 完整臂外购比例 × 外购完整臂中协作厂商的份额）。

单家供应商还要乘以其在协作厂商供货中的中标份额，并核对合格产能与交付节奏。研发、备件和替换需求单列；从装机需求推算当期供应商出货时，再调整库存、跨期交付与退货。目标产能不能替代合格产出。

三处最容易误判：

- **出货结构不是外购率。** “人形臂占某协作厂商出货的比例”，分母是该厂商出货；“OEM整臂外购率”，分母是对应机型的装机臂需求。
- **客户结构变化不等于采购策略变化。** 自研OEM增长更快，即使每家客户策略不变，全市场加权外购率也可能下降。
- **订单不是当期装机。** 合作、定点、订单、出货和验收是不同阶段；同一批货应跟踪状态，不能在各阶段重复累计。

若研究收入，还须统一控制器、传感器、服务及税费的报价边界，分开观察同型号净价和配置结构。完整臂收入不与其内部关节价值重复加总，也不与整机收入合并成一个市场。

<a id="evidence"></a>

## 5. 公开案例验证了哪些环节

下列事实来自企业公开披露；每项仅支持其对应环节，不能代替全行业数据。

| 公开证据 | 支持的判断 | 仍需验证 |
|---|---|---|
| 天机披露与中科慧灵合作并完成首批Marvin机械臂交付；该批版本未配置力控模块，面向抓取、搬运及轨迹任务。[2025-10-17公告](https://www.gentorobotics.ai/news/tianji-humanoid-arm-secures-strategic-order/) | 已存在整臂采购与交付；产品配置按任务取舍 | 实际验收、持续复购、具体机型份额；不能据此推断所有客户均需力控 |
| 珞石披露获得智元“优秀供应商伙伴”奖，并介绍AR机械臂与HSA力控关节。[2026-04-24公告](https://www.rokae.com/cn/news/show/2467/%E7%8F%9E%E7%9F%B3%E6%9C%BA%E5%99%A8%E4%BA%BA%E8%8D%A3%E8%8E%B7%E6%99%BA%E5%85%83%E2%80%9C%E4%BC%98%E7%A7%80%E4%BE%9B%E5%BA%94%E5%95%86%E4%BC%99%E4%BC%B4%E2%80%9D%E5%A5%96.html) | 存在供应合作，供应商可布局整臂与关节两种产品 | 哪些机型采购哪类产品、各自数量与份额；不代表智元全部外购或独家采购 |
| UR与Scale AI发布AI Trainer，通过遥操作同步采集运动、力和视觉数据。[2026-03-16公告](https://www.universal-robots.com/news-and-media/news-center/universal-robots-scale-ai-launch-imitation-learning-system-accelerate-ai-training-lab-to-factory/) | 成熟协作平台可以服务模型训练，形成相邻的采集设备需求 | 付费采购与利用率；该案例不能证明UR机械臂装入人形整机 |

以上证据支持“存在采购、交付与相邻产品”的判断。全行业外购率、供应商份额和跨代复购仍缺少统一数据；订单新闻也不足以证明普遍供不应求，需另查交期、按时交付、质量和取消订单。

<a id="tracking"></a>

## 6. 竞争最后落在持续供货能力

竞争同时来自其他完整臂厂商、独立关节供应商及OEM自研；采集场景还要比较其他训练平台。值得验证的优势是：合格批量交付、接口易用、适配投入下降，以及成熟方案能否跨客户复用。单一性能参数、客户数量或产品发布数量，均不足以证明这些优势。

整臂与关节双线布局可以承接不同采购路径，但整臂订单流失不等于关节销售能够等额补回。更有意义的持续性证据，是同代机型重复采购、下代机型继续定点，以及在规格和价格变化后仍能完成验收。

| 优先追问 | 所需证据 |
|---|---|
| OEM为什么买，下一代还买吗？ | 分机型的采购理由、配置变更、自研计划与下一代选型 |
| 宣布的订单交付了多少？ | 订单批次对应的单臂出货、验收、取消和退货记录 |
| 装机需求还是研发需求？ | SKU、最终用途、工位配置及客户库存 |
| 产品能否可靠复制？ | 同工况的故障、温升、维护、按时交付及适配投入 |

记录粒度采用“供应商—OEM—机型—用途—期间”，订单批次贯穿各阶段。指标纳入[统一跟踪表](../04_tracking/metrics.md)，证据缺口纳入[待验证问题](../04_tracking/questions.md)。后续与应用专题配对时，从具体任务的负载、接触、节拍和维护要求回推机械臂选型，再检查模型接口和真实验收结果。
